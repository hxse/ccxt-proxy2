# 换月过渡窗口

## 任务边界

遵循[共同契约](<../20260926A market data caching and maintenance/spec_01_contract.md>)与[日历/映射前置](<../20260926A.004 tq calendar and mapping/spec.md>)。在既有映射入口增加过渡参数和 records，不新增独立过渡 HTTP 路由。

不改变主连或加权行情价格，不保存全部旧合约历史，不引入 interval 推算、联合多合约 serial、缓存与网络拼接证明。停止线是起点可靠、单次资格清楚、长度变化和并发保持完整窗口。

## 任务规范

### 身份和起点

窗口身份包含 provider=tq、mode=live、主连 symbol、真实 roll_date、新 underlying_symbol、old_symbol、周期和原始价格 variant。N 不进入身份；旧合约价格固定不复权，不从普通主连行情回算。

节点来自可信日映射中第一个新合约出现的位置。先重新取得官方历史源并按实际行情日期确定已生效节点，固定该源及日历上下文，再取过渡；不读取 SDK 当前标的，过渡也不重新刷新元数据快照。不能把请求起点、响应第一日或缓存清理后的首日当作换月日。

只处理不晚于本次实际生效日 D 的可靠节点。官方预公布但尚未生效的事件不触发旧合约取数或过渡写入，不能为预公告提前伪造价格窗口。

旧合约为空时返回空过渡，不猜合约。节点身份修订后必须查其完整新身份，不能误用旧窗口；不用删除全部旧历史来完成身份修正。

### 获取和目标定位

K 为该身份已完整保存的根数。缓存开启且 K≥N 时，读取同一窗口的前 N 根，不请求旧合约 SDK、不缩短缓存。否则直接使用前置任务的无落盘 SDK 获取入口，一次请求旧合约该周期最新 10000 根，并固定稳定副本。

不调用 /tq/fetch_ohlcv 的带缓存业务入口，不将筛选用一万根交给普通缓存，不为补足目标调用第二个窗口。SDK 自身 serial 可复用。

从 SDK 实际时间轴定位 roll_date 起该周期的第一根旧合约数据，使用前置任务提取的交易日归属和可靠日历处理夜盘。必须证明未漏掉该日更早的目标根：例如稳定序列含目标首根及其前一根，前驱属于较早交易日，目标首根属于 roll_date，且原生 id 连续。

若源窗口从 roll_date 当日中途开始、已经晚于节点、缺少证明起点的上下文，不能用后面的 N 根冒充。只使用本次正常结果中已有的可靠起点证据；不能证明就按既定契约返回空过渡，不为上市首日、前驱缺失或久远历史新增上市信息查询、起点探测或额外窗口恢复。不能仅凭结果第一行推断它是目标首根。

大周期横跨换月、首根无法唯一归属时跳过该节点过渡。不得将未来下一周期第一根移作本次起点；日周期及周周期也按真实序列判断，不用周期乘数量。

目标窗口必须是同一旧合约、同一周期、正确起点、时间严格升序、原生 id 连续的前 N＋1 根。有限价格、OHLC 关系和非负 volume 同时验证；非法数据报错，不删除中间坏行后凑数。

### 提交和响应

```text
单次稳定 SDK 副本含目标 N＋1 根
→ 完整提交这 N＋1 根，批次末根标记未知
→ 缓存调用普通尾根筛选得到 N 根
→ 整个窗口原子保存/替换
→ 响应前 N 根
```

不足 N＋1 但起点可靠时，返回本次实际取得的最多 N 根，完全不写过渡缓存；已有较短 K 保持原样。不能将 N−1 根作为普通行情部分提交。起点不可靠或目标已完全超出源窗口时，返回空数组。

N＋1 必须来自同一次调用结果，不能用已有 K、另一 SDK 请求或主连价格拼凑。第 N＋1 根只是传入缓存的证明行，不出现在用户前 N 根，不落盘为价格记录；筛选后的 N 根和以后缓存读取都不再次去尾。

同一有效短窗口响应不保证仍在走，可能是到期、历史不足或源窗口限制。网络/格式失败仍按准确错误返回，不冒充正常空过渡。

enable_cache=false 不读窗口、不读取缓存前驱、不提交价格，前驱来自同次自有映射源；仍执行全部起点和单次校验。

### 并发与存储

schema 3→4 增加 transition_windows/transition_rows，迁移保留已有数据。窗口拥有一个 segment_id，kind=transition、time_unit=ns；价格表存整数 datetime 和 old_open/high/low/close/volume，窗口存完整身份、实际首尾和 K。

公开缓存入口为 read_transition_prefix(identity,count) 和 submit_transition_window(identity,target_count,batch)。读取返回完整命中或 miss；提交接收未提前删尾的目标 N＋1 根和末根未知状态，检查资格并共用普通尾根筛选。

网络在锁外；写锁内重新读取 K，以筛选后的目标 N 比较。N<K 不替换，N=K 可整窗有效修订，N>K 用本次完整窗口整体替换。不能逐行混合两次来源，也不走普通多片段吸收补长。

窗口行与 segment 元数据在同一事务更新，读取只见提交前或后的完整版本。较短请求迟到不能覆盖更长窗口；写入失败保留旧窗口。清理接口以后按实际 K 整窗删除，不使用最近一次用户请求量。

### 失败与边界

参数错误在网络前拒绝；过渡结构/连续性错误返回 422 TQ_INVALID_TRANSITION_WINDOW，当前节点上下文错误沿用映射错误。普通缓存写失败记录 error，已确认官方目标仍可返回；不能宣称窗口写入成功。

每个 SDK 获取遵守前置任务有限等待；整次含过渡的映射查询另设 45 秒总预算，超过返回 504 TQ_TRANSITION_TIMEOUT，不为剩余节点无限继续。取消后不启动新窗口；已经独立成功提交的完整窗口可保留，不能将未完成整份 HTTP 响应冒充成功。

## 公开接口与用户写法

在 /tq/fetch_underlying_symbol 增加：

| 参数 | 规则 |
| --- | --- |
| transition_timeframe | 可选；s/m/h/d/w 正整数周期，转换后满足 TQ duration_seconds 规则；不将 M 当分钟/月秒数 |
| transition_bars | 默认 10；正整数，N＋1≤用于筛选的 SDK 窗口上限，目前 1..9999 |

上限由同一个 SDK 窗口常量推导，不散落另一份 9999 业务魔数。周期需要成对历史范围；仅提供数量不启用过渡。无周期时 history 节点省略 transition 字段，不能为过渡多取旧价格。

```text
GET /tq/fetch_underlying_symbol?symbol=KQ.m@SHFE.rb&start_time=1790125200000000000&end_time=1790211600000000000&transition_timeframe=5m&transition_bars=10
```

响应节选为格式示例：

```json
{"items":[{"symbol":"KQ.m@SHFE.rb","underlying_symbol":"SHFE.rb2701"}],"history":[{"date":"2026-09-24","symbol":"KQ.m@SHFE.rb","underlying_symbol":"SHFE.rb2701","old_symbol":"SHFE.rb2610","transition":[{"datetime":1790211600000000000,"old_open":3500,"old_high":3510,"old_low":3490,"old_close":3505,"old_volume":100}]}]}
```

transition 挂在真实节点上，不在每日重复；窗口可跨自然日，不按天重新累计。已请求周期但没有可靠窗口为 []，old_symbol 未知为 null。价格字段以 old_ 区分，不改变节点 underlying_symbol 指向新合约的含义。

| 请求序列 | 预期 |
| --- | --- |
| 首次 N=5，单次取得 6 根 | 提交 6，保存/返回 5，K=5 |
| 再次 N=3 | 读前 3，K 仍为 5 |
| 再次 N=10，取得 11 根 | 完整替换为 10，K=10 |
| 请求 N=10，仅可靠取得 8 根且原 K=5 | 返回本次 8，K 仍为 5，不拼接 |
| 请求 N=5 时并发已提交 K=10 | 不缩短 K |

非法数量/周期为 400 TQ_INVALID_TRANSITION_BARS / TQ_INVALID_TRANSITION_TIMEFRAME；缺少历史范围为 400 TQ_INVALID_DATE_RANGE。后台可以只请求 5m，用户仍可指定其他合法周期。

## 测试、验证与阶段过渡

实现阶段通过 just test、just lint、just check；文档阶段不运行。用离线固定源与 SDK 副本验证真实节点、夜盘、周末、窗口头部丢失、单日中途截断、无法证明起点时返回空、大周期无法定位、旧合约缺失和合法短响应。预公布未来节点不得发起过渡取数，不将上市前恢复列为必须成功的目标。

覆盖 N=1、默认 10、上限、5→3→10、同长修订、短请求迟到、缓存关闭、全窗替换和删除一致快照。反向用例明确拒绝缓存＋网络或多次 SDK 拼成 N＋1，不以一个 segment_id 替代单次证据。

断言缓存收到完整 N＋1 且共用筛选，最终只 N 根落盘；不足不写，网络失败不变成空成功；旧合约一万根不进入普通行情表。原始主连与加权数据不被修改。

参数、响应模型、OpenAPI、Bruno 和映射调用方同步更新；当前规范补充过渡专属主题并链接共同尾根规则，避免再次写一套筛选逻辑。未携带周期的既有映射响应保持无 transition，元数据硬禁与自动刷新回归必须通过。

更新在线用例定义但留待最终单次 live 验证；长期历史无法取得过渡是已接受限制，不以付费历史接口或额外试探算法补齐。
